### Home Assistant MQTT Sensor Configuration for Rolectro R12

This repository contains comprehensive MQTT sensor configurations for integrating Rolectro R12 energy monitoring devices with Home Assistant.

**Files:**
- `mqtt_sensors.yaml` - Complete Home Assistant MQTT sensor configuration
- `mqtt_discovery_config.json` - MQTT discovery configuration payloads
- `MQTT_SENSORS_README.md` - Detailed documentation and usage guide

**Features:**
- 🔌 Three-phase voltage and current monitoring
- ⚡ Active, reactive, and apparent power measurements
- 📊 Energy import/export tracking (compatible with Home Assistant Energy Dashboard)
- 📈 Power factor monitoring
- 🌡️ Temperature monitoring
- 📡 Total Harmonic Distortion (THD) measurements
- 🔄 Binary sensor and switch control

For detailed information, see [MQTT_SENSORS_README.md](MQTT_SENSORS_README.md).
